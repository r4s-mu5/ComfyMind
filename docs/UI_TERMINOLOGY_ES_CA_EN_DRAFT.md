## Recommended wording choices

### Use “obra” rather than “imagen” when referring to the patient’s completed creative work

This gives the result more dignity and makes it feel like art rather than a technical output.

Use “imagen” or “imatge” when referring to:

- uploaded source files
- generated image files
- technical image operations

Use “obra” when referring to:

- saved patient creations
- gallery items
- work produced during a session

### Use direct action labels

Prefer:

- Guardar / Desa / Save
- Continuar / Continua / Continue
- Crear una imagen / Crea una imatge / Create an image

Avoid overly technical labels such as:

- Ejecutar workflow
- Procesar prompt
- Enviar a ComfyUI

### Proposed replacement for the current free-generation label

Current Spanish:

- Imágenes de generación libre

Recommended shorter label:

- Español: Creación libre
- Català: Creació lliure
- English: Free creation

This is easier to scan in navigation.

## Items requiring approval

Please review these choices:

1. “Obra” versus “creación” for saved patient results.
2. “Creación libre” versus “Generación libre”.
3. “Mi sesión” versus “Sesión actual”.
4. Whether “Paciente” and “Terapeuta” should be visible role labels in the interface.
5. Whether the application should use formal or informal language in Spanish and Catalan.
