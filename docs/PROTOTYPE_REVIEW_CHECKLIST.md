# ComfyMind prototype review checklist

## Before the meeting

- [ ] ComfyUI starts and is reachable at `http://127.0.0.1:8188`
- [ ] Backend starts and is reachable at `http://127.0.0.1:8000/docs`
- [ ] Frontend starts and is reachable at `http://localhost:5173`
- [ ] Prototype branch is active
- [ ] `npm run build` succeeds
- [ ] Login screen opens
- [ ] Patient home opens
- [ ] Session/workspace screen opens
- [ ] Artwork result or gallery screen opens
- [ ] Language selector switches between Catalan, Spanish and English
- [ ] No real patient data appears in the prototype

## Questions for stakeholders

- Does the design feel appropriate for adult patients?
- Is the main action obvious on each patient screen?
- Is the amount of information comfortable?
- Does anything feel childish, clinical or confusing?
- Are the labels understandable?
- Are buttons and controls large enough?
- Which actions should appear on the patient home screen?
- Is a therapist preview needed in the next iteration?
- Which accessibility needs should be prioritized after the meeting?
