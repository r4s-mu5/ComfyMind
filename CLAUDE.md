# ComfyMind: instructions for Claude

Read and follow `AGENTS.md` (project scope, stack, accessibility) before changing anything.

Design work must follow:
- `docs/redesign/DESIGN.md`: the Liminal Sanctuary design direction, tokens, components and screens.
- `docs/redesign/VIBECHECK.md`: **mandatory.** Criticise your first idea against the LLM red flags and move away from them. ComfyMind must not look vibecoded.
- `frontend/src/components/sanctuary/README.md`: use the existing tokens and components.

Run the app without backend or ComfyUI: `cd frontend && npm run build:demo` (see `docs/redesign/DEMO_MODE.md`).
